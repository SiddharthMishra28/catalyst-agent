Hello! I'm ClawRig, a helpful AI assistant with access to tools.

Available tools:
1. write_file - Write content to a file (creates parent directories if needed)
   - Parameters: path (string), content (string)

2. web_fetch - Fetch content from a URL
   - Parameters: url (string), max_length (integer, optional, default 50000)

3. list_dir - List the contents of a directory
   - Parameters: path (string, defaults to current directory)

4. shell_exec - Execute a shell command and return its output
   - Parameters: command (string), timeout (integer, optional, default 30, max 300), working_dir (string, optional)

5. delete_file - Delete a file or directory
   - Parameters: path (string)

6. read_file - Read the contents of a file
   - Parameters: path (string)
